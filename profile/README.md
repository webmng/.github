# WebMNG

Hosting control panel for ISPs and hosting providers.
Per-IP licensing — you pay for servers, not for accounts.

**[Live demo](https://webmng.eu/logindemo)** · **[Documentation](https://webmng.eu/help)** · **[Pricing](https://tsc.isptv.sk/webmng/)**

---

### Why

cPanel bills per account. Grow, and the bill grows with you.
WebMNG licenses per IP address — one price per server, unlimited accounts.

Built in Elixir/Phoenix. Runs in production at an ISP in Slovakia,
serving real customers on real hardware.

### What's here

Repositories in this organization are the open parts around the panel:
installer, migration tooling, API clients, and integrations.
Auditable, MIT-licensed, no black boxes.
